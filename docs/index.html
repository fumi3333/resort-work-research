リゾートで働く人と、受け入れる施設のための
労働条件の基礎データ

リゾート地の短期・住み込みの仕事について、時給や寮・食事の条件を地域・職種ごとに集計し、毎月公開しています。働く人が条件を比べるとき、施設や派遣会社が求人の条件を考えるとき、自治体が観光地の人手を考えるときの材料として、無料で使えるようにすることが目的です。

このレポートについて

元のデータは、派遣会社各社が公開している求人ページです。利用の条件を確認できた5社の、掲載中で時給が書かれている求人だけを使っています。集計の手順とコードはすべて公開しているので、同じ計算を誰でも確かめられます。
