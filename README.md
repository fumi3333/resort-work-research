# リゾートワーク労働条件レポート

リゾート地の短期・住み込みの仕事（リゾートバイト）について、時給や寮・食事の条件を地域・職種ごとに集計し、毎月公開しています。

- サイト：https://fumiproject.dev/resort/research/
- 作成：松田晴史（武蔵野大学 経済学部）

## 中身
- `analysis/build.py`：求人データから集計表と分析結果を作る（元の求人データはこのリポジトリに含みません）
- `analysis/site.py`：集計結果から公開サイト（`docs/`）を作る
- `docs/data/`：集計表（CSV）と分析結果（JSON）

## 公開の条件
特定の会社や施設が分かってしまわないよう、集計の枠ごとに、求人10件以上・3社以上・1社の割合が60%以下・施設5か所以上の条件をすべて満たす場合にのみ数値を掲載しています。時給は10円単位、件数は10件単位に丸めています。個別の求人・会社名・施設名は掲載していません。
